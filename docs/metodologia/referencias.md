# Referencias metodológicas

Las marcadas con ● están en `referencias_locales/` (carpeta no versionada). Solo se pueden redistribuir las que tienen licencia abierta, indicada en cada entrada. En el repositorio se citan, nunca se copian.

Estado de verificación de los DOI, al 2026-09-25:

- "(en el PDF)": tomado del propio documento;
- "(verificado)": confirmado en la página del editor o en un índice;
- "(por verificar)": pendiente.
